# Crypto Bot — Bybit Demo (мульти-агентный)

Торговый бот для **Bybit Demo Trading** (виртуальные деньги, реальные рыночные данные).
USDT-перпетуалы BTCUSDT / ETHUSDT / SOLUSDT, плечо x3, бюджет 300 USDT.
Полное управление через Telegram с телефона.

## Как это работает

Каждую минуту бот опрашивает рынок. По закрытию 15-минутной свечи 5 внутренних
агентов голосуют по каждой паре (оценка от −100 до +100):

| Агент | Вес | Анализирует |
|---|---|---|
| trend | 30% | EMA 50/200 на 1ч (режим), EMA 20/50 на 15м, сила тренда ADX |
| momentum | 30% | RSI(14), гистограмма MACD и её наклон |
| volume | 15% | наклон OBV против цены (подтверждение/дивергенция), всплески объёма |
| volatility | 10% | Bollinger, сжатие, экстремальный ATR → «переждать» |
| llm | 15% | Claude (опционально, выключен по умолчанию) |

Взвешенная сумма ≥ +35 → лонг, ≤ −35 → шорт, разворот против позиции → закрытие.

**Риск-менеджмент:** 2% бюджета на сделку (убыток на SL), SL = 1.5×ATR, TP = 2.5×ATR
(ставятся на бирже сразу при входе), максимум 2 позиции одновременно, дневной
убыток −6% → автопауза, кулдаун 3 свечи после закрытия сделки.

## Настройка (один раз)

1. **Демо-аккаунт Bybit:** на bybit.com наведи на иконку профиля → **Demo Trading**
   (Демо-торговля). Внутри демо-кабинета: профиль → **API** → создать ключ →
   права Read + Trade (Contract/Unified). Скопируй Key и Secret.
2. **Telegram-бот:** в Telegram открой **@BotFather** → `/newbot` → любое имя →
   получишь токен. Затем открой **@userinfobot** → `/start` → он покажет твой `Id`.
3. Скопируй `.env.example` в `.env` и заполни:
   ```
   BYBIT_API_KEY=...
   BYBIT_API_SECRET=...
   TELEGRAM_TOKEN=...
   TELEGRAM_CHAT_ID=...
   ```
4. Зависимости (если ещё не стоят): `pip install -r requirements.txt`

## Запуск

```
cd D:\crypto-bot
python main.py
```

Бот пришлёт в Telegram «🤖 Бот запущен» и дальше сам сообщает о каждой сделке.

## Команды в Telegram

- `/status` — состояние, позиции, PnL за день
- `/balance` — демо-баланс и бюджет бота
- `/positions` — открытые позиции подробно
- `/pause` / `/resume` — пауза/возобновление торговли
- `/close BTCUSDT` или `/close all` — закрыть позицию(и)
- `/report` — журнал последних сделок, винрейт
- `/help` — список команд

## Облачный режим: GitHub Actions (бесплатно, без своего сервера)

Файл `.github/workflows/bot.yml` запускает `runner_once.py` каждые ~15 минут на
серверах GitHub: один проход = команды из Telegram → сверка позиций → анализ →
сделки → выход. Состояние (журнал, пауза, кулдауны) живёт в `bot.db`, который
коммитится обратно в репозиторий. SL/TP стоят на бирже, поэтому между запусками
позиции защищены.

Настройка: публичный репозиторий (у публичных минуты Actions бесплатны без
лимита) → Settings → Secrets and variables → Actions → добавить секреты
`BYBIT_API_KEY`, `BYBIT_API_SECRET`, `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID`
(опционально `ANTHROPIC_API_KEY` + переменную `LLM_ENABLED=1`). Ключи хранятся
в Secrets и в код не попадают. Команды из Telegram применяются с задержкой до
15 минут — бот честно предупреждает об этом в /help.

## Опционально: LLM-аналитик

В `.env`: `ANTHROPIC_API_KEY=...` и `LLM_ENABLED=1`. Раз в час на пару Claude Haiku
оценивает рынок и голосует наравне с остальными агентами (стоит копейки, но
требует ключ Anthropic).

## Параметры

Всё настраивается в `config.py`: пары, плечо, бюджет, риск, таймфреймы, пороги.
